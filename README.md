# 🤖 JARVIS - Akıllı AI Asistan

Tam bilgisayar kontrolü sağlayan, her türlü komutu anlayıp çalıştırabilen akıllı AI asistan.

## 🚀 Hızlı Başlangıç

```bash
cd jarvis_v2
bash start_agent.sh
```

Tarayıcıda aç: http://localhost:5174

## 📚 Dokümantasyon

Detaylı bilgi için: [jarvis_v2/README.md](jarvis_v2/README.md)

## 🎯 Özellikler

- 💭 Düşünce ve görüş soruları
- 📚 Web araştırması + AI sentezi
- ⚡ Sistem kontrolü ve otomasyon
- 🎨 Modern web arayüzü
- 🔌 Real-time WebSocket iletişimi

## 🛠️ Gereksinimler

- Python 3.8+
- Node.js 16+
- macOS (şu an için)
- OpenAI veya Gemini API anahtarı
